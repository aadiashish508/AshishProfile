# 🚀 Ashish Kumar - Personal Portfolio

A modern, interactive **3D personal portfolio website** for **Ashish Kumar** — Computer Science Engineering student at Lovely Professional University (LPU), Punjab, India, passionate about Cloud Computing, DevOps, Linux, and modern software technologies.

## ✨ Highlights

- **3D Interactive Character** powered by **Three.js** & WebGL
- High-performance dark futuristic aesthetic
- Cinematic scroll transitions & text animations with **GSAP** & **ScrollTrigger**
- Smooth inertial scrolling with **Lenis**
- Dedicated **Showcase of Projects** (Smart Drainage Monitoring System, Arduino Sensor Learning Kit, AR/VR Virtual Space Museum)
- Dedicated **Certificates Section**
- Dedicated **CV / Resume Page** with dual-pane PDF viewer and photo framing
- Interactive **AI Chess & Chat Experience**
- Fully responsive across desktop, tablet, and mobile devices

## 🧰 Tech Stack

- **React 18** + **TypeScript**
- **Three.js** + **@react-three/fiber** + **three-stdlib**
- **GSAP** + **ScrollTrigger**
- **Lenis** Smooth Scroll
- **React Router 7**
- **Vite**

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run locally in development mode
npm run dev

# Build for production
npm run build
```
